# Landing Page Numera

## Sobre o projeto
Este é um projeto front-end contendo uma Landing Page Cinematográfica Premium para a Numera, uma contabilidade digital focada em empreendedores. O projeto serve como infraestrutura base de UI/UX, utilizando layouts fluídos, tipografia moderna e animações imersivas sem depender de bibliotecas CSS pesadas.

## Telas do Projeto
Página Inicial | Hero Section | Sessão de Serviços | Manifesto

## Funcionalidades
- Landing Page minimalista, elegante e 100% responsiva.
- Grid Bento assimétrico e layout otimizado para leitura.
- Animações avançadas de scroll e entrada utilizando GSAP.
- UI/UX polida utilizando design flat sólido e tipografia moderna (Manrope/Satoshi).
- Alta performance e carregamento rápido garantidos por tecnologias Vanilla.

## Tecnologias
**Frontend:**
- HTML5 Semântico
- CSS Vanilla (CSS Variables, Flexbox, CSS Grid, Clamp)
- JavaScript Vanilla
- GSAP (GreenSock Animation Platform)

## Pré-requisitos
Antes de começar, certifique-se de ter instalado em sua máquina:
- Um navegador web moderno (Chrome, Edge, Firefox, Safari)
- Git (Opcional, para clonar o repositório)

## Instalação
1. Clonando o repositório
```bash
git clone https://github.com/vitor-nery11/landing_page_numera.git
cd front_designer
```

## Como executar
Por ser uma aplicação baseada inteiramente em arquivos estáticos locais (Vanilla HTML/CSS/JS), o projeto não necessita de etapas de compilação ou build. 

**Executar via extensão de editor (Recomendado):**
1. Abra a pasta do projeto no VSCode.
2. Utilize a extensão Live Server para iniciar a página em um servidor local.
3. Acesse a aplicação no navegador através de: `http://localhost:5500` (ou a porta fornecida pela extensão).

**Executar nativamente:**
Basta dar um duplo clique no arquivo `index.html` dentro da pasta `front_designer` para abri-lo diretamente no seu navegador padrão.

## Testes
Os testes da interface e da responsividade podem ser feitos rodando o projeto manualmente:
1. Abra o arquivo `index.html` no navegador.
2. Utilize a ferramenta de inspecionar elementos do navegador (F12) para simular dispositivos móveis e verificar a fluidez do Grid CSS em diferentes resoluções.
